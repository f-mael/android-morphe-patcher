# android-morphe-patcher

Compilaciones automatizadas de Brave Browser para Android parcheadas con Morphe (`dh6k/morphe-patches`).

### Qué incluye este repositorio

- **Binarios listos para usar**: APKs parcheados de Brave (`Stable`, `Beta`, `Nightly`) para arquitecturas `arm64-v8a`, `armeabi-v7a` y `universal`.
- **Fondo de nueva pestaña personalizado**: Integración de imagen de inicio (`Custom NTP wallpaper`).
- **Mejoras de rendimiento y ajustes base**: Optimizaciones en el arranque de la app y desbloqueo de funciones de origen integradas en el parcheador.
- **Entregas automáticas**: Generación periódica y firma de APKs disponibles directamente en la sección de [Releases](../../releases).
